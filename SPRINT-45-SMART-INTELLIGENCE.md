# Primovex Sprint 45

## Smart Intelligence Foundation

Release: v0.13.0

This release adds the first operational intelligence platform services without changing the approved desktop or mobile interface.

### Included

- Operational Fact schema
- Multi-source Evidence schema
- Confidence and freshness calculation
- Conflict, staleness, and safety-unknown anomaly detection
- Ambient Verification candidate generation
- Local Operational Memory repository
- React operational-memory hook
- Existing Operations Engine integration
- Information Health output

### Preserved

- Desktop experience
- Role-adaptive mobile experience
- Login flow
- Persistent mobile navigation and safe-area behaviour
- Space Registry
- Existing Operations Brief and readiness calculations
