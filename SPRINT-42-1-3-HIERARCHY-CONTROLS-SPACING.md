# Primovex v0.11.1
## Hierarchy controls and page spacing patch

- Added delete controls to sites, floors and zones in the shared Sense Spaces hierarchy.
- Deleting a floor or zone preserves permanent Space IDs, Smart Tags and history, while affected spaces become unassigned.
- Sites with child floors, zones or active spaces are protected from deletion.
- Added confirmation messaging before structural changes.
- Increased desktop page bottom spacing globally so long pages and final cards do not sit against the bottom edge.
- Shared behaviour applies wherever Space Builder is embedded: Practice Administration, Sense and Facilities.
- Primovex Mobile continues to read the same shared registry and reflects hierarchy changes.
