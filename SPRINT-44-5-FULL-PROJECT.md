# Primovex Sprint 44.5 v0.11.8 - Full Project

This package is the complete Primovex project assembled from the user's latest full Sprint 44 baseline,
with the reviewed Sprint 44.5 Adaptive Navigation Shell applied.

Important:
- This is intended to replace the current project source folder.
- Keep a backup of the existing project before replacement.
- Generated dependency/build folders may be excluded and can be recreated with npm install/build.
- Android signing secrets or machine-local environment files should be retained separately if they were
  not present in the uploaded full baseline.

After extraction:
1. npm install
2. npm run build
3. npm run dev

Then verify login, desktop sidebar, every route in Developer Centre route audit, Theme, Sense/Spaces,
Temperature, Connect, mobile preview, and mobile bottom navigation before producing a new APK.
