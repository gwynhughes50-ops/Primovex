# Sprint 42.1.1 — Sense Room Tags & Mobile Parity

Version 0.10.10

## Delivered
- Prominent desktop room Smart Tag setup workflow
- Three-step write, test and place guidance
- Selected room flows directly into the tag writer
- Registered tag test, disable, replace and status controls retained
- Mobile mini Sense room card for active locations
- Mobile room shortcuts for stock, cleaning, issues and checks
