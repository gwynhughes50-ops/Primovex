# Primovex Sprint 44.4 v0.11.7

Apply this overlay to the existing Sprint 44.3 v0.11.6 project.

1. Keep the existing project folder.
2. Copy the contents of this ZIP into the project root.
3. Allow matching files to be replaced.
4. Run:

```powershell
npm install
npm run build
npm run dev
```

Do not delete the project first. This overlay does not contain Android signing files, Firebase configuration, or the full application.
