# Design System

## Foundation

MedTrak+ uses a central theme and icon system:

- `src/config/medtrakTheme.js`
- `src/config/medtrakIcons.js`

## Component Principles

Prefer reusable components from:

- `src/components/common`
- `src/components/ui`

Current common components include:

- `PageHeader`
- `SectionCard`
- `StatusBadge`
- `EmptyState`

## Visual Language

- Dark calm operational surface
- Teal/emerald highlights for positive action
- Amber/orange for watch items
- Rose for urgent risk
- Slate for neutral structure

## Rule

Do not create one-off styling patterns where an existing shared component can be used.
