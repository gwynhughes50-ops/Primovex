# v0.9.31 - Project Renaissance Demo Experience

## Summary

This release makes Demo and Training modes feel like a real product demonstration rather than an empty shell. It introduces a believable fictional practice, richer data, safer synthetic-mode data flows and a more polished login experience.

## Highlights

- Login page redesigned as a wider MedTrak+ landing/sign-in experience.
- Demo Centre renamed visually around "Experience MedTrak+".
- Added synthetic Oakfield Medical Centre dataset.
- Demo data now feeds key hooks/services instead of only the `/demo` page.
- Demo/Training/Staging modes populate stock, Connect, notifications and governance workflows.
- Synthetic modes avoid writing governance changes to live Firestore.

## Testing

- `npm run build` passed successfully.

## Notes

The demo dataset is deliberately synthetic and must never be mixed with live practice or patient data.
