# v0.9.29 - Demo Centre

## Summary

This release turns the previous anonymised demo preview into a proper MedTrak+ Demo Centre.

The Demo Centre is designed for safe product demonstrations, staff training and internal testing without exposing live patient-identifiable information.

## Added

- Public `/demo` route.
- Demo Centre page with selectable scenarios:
  - GP Practice
  - Research Practice
  - Large Health Centre
  - Training Mode
- Scenario-specific MedAI demo briefs.
- Scenario-specific platform metrics.
- Local demo profile persistence.
- Reset demo data action using local browser state.

## Updated

- Login page link now says `Launch Demo Centre`.
- Demo mode configuration now includes helper functions for selecting and resetting demo profiles.
- Demo dataset now supports multiple scenario profiles.

## Data Safety

All demo records must remain synthetic. Demo cases should continue to use anonymised identifiers such as EMIS-style numbers, initials and DOB placeholders rather than patient names.

## Manual Steps

No Firestore change is required.

Optional local setting:

```env
VITE_DEMO_MODE=true
```

Restart Vite after changing `.env` values.
