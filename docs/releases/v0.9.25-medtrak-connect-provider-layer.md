# v0.9.25 - MedTrak Connect Provider Layer

## Summary

Sprint 25 turns MedTrak Connect into a provider-based platform rather than a single thermometer integration.

## Added

- Provider layer for MedTrak Connect.
- Simulator provider for safe development without hardware.
- Tuya provider shell for future cloud integration.
- Provider manager UI in the Connect page.
- Backend contract display for Tuya sync.
- Device registry fields for provider, equipment, firmware, signal, battery and safe range.
- Simulated -40°C freezer device for ultra-low temperature monitoring workflows.

## Security

Tuya Access Secret must not be stored in the frontend. The React app should only store non-secret metadata such as region, Access ID, project ID and device ID. Live Tuya sync should be implemented through Firebase Functions or another backend service.
