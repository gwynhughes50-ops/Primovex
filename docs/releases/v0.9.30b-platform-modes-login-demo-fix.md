# v0.9.30b - Platform Modes Login and Demo Fix

## Summary

This hotfix improves the Platform Modes release by polishing the login screen and fixing the demo/training launch flow.

## Changed files

- `src/pages/Login.jsx`
- `src/components/platform/PlatformModeControls.jsx`
- `src/contexts/AuthContext.jsx`
- `src/layout/Layout.jsx`
- `docs/CHANGELOG.md`
- `docs/releases/v0.9.30b-platform-modes-login-demo-fix.md`

## Improvements

- Full-width professional login design.
- Clear Launch Demo Centre action.
- Better Live / Demo / Training / Staging selector.
- Demo and training modes create a safe synthetic user context.
- Demo Centre can be opened without using live Firebase login.
- Layout sign-out now uses the AuthContext sign-out flow, so synthetic modes safely return to Live.

## Testing notes

The archive used in this environment still has the Rollup optional native dependency issue, so the full Vite build could not be completed here. Run locally:

```bash
npm install
npm run build
npm run dev
```

Then test:

1. Open `/login`.
2. Select Demo or Training.
3. Click `Open Demo Centre`.
4. Confirm demo data appears on `/demo`.
5. Open `/dashboard` while in Demo mode and confirm the synthetic session bypasses live Firebase login.
6. Sign out and confirm the app returns to Live login.
