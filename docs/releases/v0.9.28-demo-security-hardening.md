# v0.9.28 - Demo & Security Hardening

## Summary

This release introduces a safer demonstration layer and a Security Centre so MedTrak+ can be shown without exposing live patient or governance data. It also improves the sign-in and password reset experience.

## New features

### Demo Mode

A public `/demo` page provides a safe product demonstration using synthetic governance and Connect data. It uses anonymised identifiers and does not display patient names.

### Security Centre

A new `/security-centre` page gives administrators a release-readiness view covering:

- demo safety
- audit logging
- password reset readiness
- governance protection
- backend-only secrets
- DPIA evidence preparation
- MFA readiness

### Login polish

The login screen now has clearer security language and a direct link to demo mode.

### Password reset polish

Password reset now uses safer generic messaging to avoid confirming whether a user account exists.

## Manual steps

Optional demo mode can be enabled locally by adding this to `.env.local`:

```bash
VITE_DEMO_MODE=true
```

Restart the Vite dev server after changing environment variables.

## Notes

This release does not implement real MFA yet. It prepares the security architecture and user interface for a later MFA and admin re-authentication sprint.
