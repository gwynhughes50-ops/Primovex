# v0.9.24 - MedTrak Mobile 3.0

## Sprint 24 focus

MedTrak Mobile has been redesigned as a task-first mobile workspace rather than a compressed desktop dashboard.

## Updated files

- `src/mobile/MobileHome.jsx`
- `src/mobile/MobileLayout.jsx`

## What changed

- Added a stronger MedTrak Mobile home screen with MedAI mobile brief.
- Added quick actions for Scan, Stock, Connect and Find Item.
- Added mobile operational summary across notifications, stock, cold chain and governance.
- Added Stock workspace mode with faster scan/search actions and low-stock focus.
- Added Me workspace mode with user role, capabilities and assigned work.
- Added safer Firestore fallbacks for governance mobile summaries.
- Improved tablet/iPad friendliness using wider cards and larger touch targets.

## Product principle

MedTrak Mobile is for completing work quickly while moving around the practice. It should not be a miniature version of the desktop application.

`npm run build` passed.
