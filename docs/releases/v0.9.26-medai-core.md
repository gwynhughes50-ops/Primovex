## Behaviour

MedAI now builds a unified operating picture from:

- assigned notifications
- governance concerns
- MedTrak Connect device intelligence
- stock and inventory thresholds

It returns:

- Daily Brief
- explainable recommendations
- cross-module insights
- priority score
- estimated admin time

## Security principle

MedAI must inherit the signed-in user's permissions. It should summarise and recommend using data the user is allowed to access, not bypass access control.
