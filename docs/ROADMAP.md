# MedTrak+ Roadmap

## v1.0 - Core Operations Platform

Focus: a coherent single-practice GP operations system.

- Operations Centre
- MedAI Daily Brief
- Practice Pulse
- Inventory
- Purchasing
- Compliance
- Practice Administration
- Notification Centre / Inbox
- Subject Access Request workflow
- Desktop and mobile parity
- Product documentation framework

## v1.1 - Governance Workspace

- Complaints workspace
- SAR dashboard expansion
- Significant Event Analysis
- Risk register
- Action tracking
- Governance reports
- HIW/CQC-style evidence packs

## v1.2 - People and Workforce

- PADR
- Mandatory training
- Recruitment
- Staff records
- Rotas
- Meeting actions
- Policy acknowledgement

## v1.3 - Practice Intelligence

- Executive dashboards
- Capacity and demand reporting
- Financial KPIs
- Operational trend analysis
- Forecasting
- MedAI Copilot phase 1

## v2.0 - Multi-Practice Platform

- Multi-tenant organisation model
- Multi-site configuration
- Practice groups / clusters
- Central reporting
- Cross-site stock visibility
- Configurable permissions
- Feature flags
- Licensing readiness

## v3.0 - Enterprise and Ecosystem

- Health board / federation views
- API marketplace
- External integrations
- Cross-practice benchmarking
- Advanced MedAI workflow automation
