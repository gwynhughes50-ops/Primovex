# ADR-002: Desktop and Mobile Parity

## Status

Accepted

## Context

GP practice staff work at desks, in treatment rooms, in stock rooms and while moving around the building.

## Decision

Desktop and mobile are equal citizens. New modules should consider both experiences as part of the definition of done.

## Consequences

- Feature matrix tracks desktop and mobile coverage.
- Mobile screens should be purpose-built rather than compressed desktop layouts.
- Releases should not be considered complete if a key workflow is desktop-only without a deliberate reason.
