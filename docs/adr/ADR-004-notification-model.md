# ADR-004: Assigned Notification Model

## Status

Accepted

## Context

Broadcast alerts create noise and notification fatigue. Practice work needs ownership.

## Decision

Notifications should be assigned to a person where possible. Reminders should be intelligent, snoozable and only escalate when overdue.

## Consequences

- Inbox views are user-centred.
- Managers are not notified about everything immediately.
- Overdue or high-risk work can still escalate safely.
