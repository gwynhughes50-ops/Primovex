# Deployment

## Current State

The current sprint ZIP contains application source and product documentation. Deployment details should be confirmed against the active Firebase/Vite setup in the full repository.

## Release Package Standard

Each future handover should contain:

```text
src/                 application code
docs/                product and engineering documentation
release-notes/       release-specific summary, where applicable
```

## Release Checklist

- Code updated
- Desktop checked
- Mobile checked
- Firestore rules considered
- Documentation updated
- Feature matrix updated
- Changelog updated
- Any architectural decision recorded
