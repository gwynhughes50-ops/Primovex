# Product Principles

## 1. One Source of Truth

Data should be captured once and reused across the platform. Avoid duplicate spreadsheets, shadow lists and inconsistent local records.

## 2. Desktop and Mobile Parity

Desktop and mobile are equal citizens. A feature is not complete until the mobile workflow has been considered and, where appropriate, delivered.

## 3. AI Assists, Humans Decide

MedAI should prioritise, summarise, suggest and explain. It should not silently perform governance-critical actions without human review.

## 4. Audit by Default

Important actions should leave an auditable trace: who did what, when, why and what changed.

## 5. Replace Manual Work

If a process currently depends on Excel, Outlook reminders, emails, sticky notes, whiteboards or repeated chasing, it should be considered for MedTrak+.

## 6. Calm NHS-Style Interface

The interface should reduce cognitive load. Urgent things should stand out; everything else should be clear, quiet and accessible.

## 7. Commercial by Design

Features should be reusable across practices. Prefer configuration over hard-coded Clarence-specific assumptions.

## 8. Explainable Intelligence

Pulse scores, AI priority scores and suggested actions must be understandable. Users should know why something is being highlighted.
