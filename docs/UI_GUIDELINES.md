# UI Guidelines

## Design Direction

MedTrak+ should feel calm, accessible and NHS-appropriate. It should reduce stress rather than add noise.

## Principles

- Clear hierarchy
- Large touch targets
- High contrast
- Avoid crowded dashboards
- Show priority before volume
- Explain why items are urgent
- Support desktop and mobile workflows

## Operations Centre Pattern

The Operations Centre should show:

1. MedAI Daily Brief
2. Practice Pulse
3. Priority counts
4. Today's MedAI priorities
5. Suggested actions
6. What's changed since yesterday
7. Live operational feed / inbox integration

## Mobile Rule

Mobile should not be a crushed desktop page. It should provide fast operational awareness and simple actions for staff working away from a desk.
