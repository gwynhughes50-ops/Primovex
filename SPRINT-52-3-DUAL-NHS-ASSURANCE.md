# Sprint 52.3 - Dual NHS Assurance

Version: 0.15.28

- Establishes NHS Wales as the primary deployment assurance profile.
- Retains NHS England controls as an explicit compatibility and good-practice overlay.
- Adds Welsh IG Toolkit, WASPI, Welsh Records Code and DHCW / Health Board evidence gates.
- Retains DSPT, DTAC, DCB0129 and DCB0160 evidence without claiming certification.
- Adds separate Wales and England readiness panels in Security Centre.
- Adds downloadable dual-framework readiness evidence.
- Adds a jurisdiction control matrix and WASPI assessment draft.
- Keeps real patient data technically locked and preserves existing synthetic ClinFlow safeguards.

This release is an engineering and evidence-readiness improvement. It does not declare Primovex legally compliant, certified, accredited or approved for live NHS data.
